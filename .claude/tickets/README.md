# Tickets

Findings the `verify-runner` (or `deploy-runner`) subagent could not safely resolve on its
own — a failing test, a type error, a `loc-check`/`dir-check` violation, a failed deploy.
One file per issue, written by the subagent that hit it.

Read these before treating a feature as done. Delete a ticket once you've confirmed its
issue is actually fixed — the subagents never delete their own tickets.
